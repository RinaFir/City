# NOCTURNE CSS City

Игровой тренажёр CSS в составе репозитория Ti. Игрок пишет обычные CSS-правила, браузер применяет их к настоящим DOM-объектам ночного города, а задания постепенно раскрывают основные темы CSS.

## Запуск

Из этой папки можно запустить статический сервер:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Состояние

Сейчас в папке находится ранний демонстрационный прототип Code Arcade. Он ещё не реализует основной цикл NOCTURNE CSS City. Не считать демонстрации полноценными игровыми заданиями.
