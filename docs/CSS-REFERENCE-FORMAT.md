# Формат справочника CSS

Этот документ фиксирует согласованный формат описания CSS-свойств для NOCTURNE CSS City. Использовать его при добавлении новых тем и свойств, не придумывать оформление заново.

## Общий принцип

Крупное свойство раскрывается на отдельные понятные пункты. Каждый пункт имеет короткое название и нормальное объяснение: что это такое, за что отвечает и какие варианты есть. Не ограничиваться перечислением терминов или значений.

Не писать длинную теорию и не раздувать функциональность. Нужны короткие, содержательные объяснения.

## Структура

Для свойства:
- Кратко объяснить, что оно меняет и где действует.
- Разбить материал на отдельные пункты по смыслу.
- Каждый пункт раскрывается отдельно.
- Внутри пункта дать пояснение и, где уместно, варианты значений и короткие примеры.

Типовые пункты (не обязательный шаблон для каждого свойства):
- **Как записать** — пример CSS и объяснение синтаксиса/порядка частей.
- **Части свойства** — что контролирует каждая часть составного значения.
- **Значения** — варианты и понятное описание результата каждого.
- **Несколько значений** — как работают одно, два или четыре значения, если это применимо.
- **Единицы** — какие единицы допустимы и что они означают, если это важно.

Добавлять только те пункты, которые действительно относятся к свойству. Не заполнять шаблон ради шаблона.

## Пример согласованного оформления: `border`

**Свойство:** рисует рамку вокруг элемента. В одной записи можно задать её толщину, вид линии и цвет.

**Как записать**
- Пример: `border: 2px solid #60a4a1;`
- Сначала указывают толщину, затем вид линии и цвет.
- Порядок этих трёх частей можно менять.
- Если часть пропущена, браузер использует её значение по умолчанию.

**Толщина**
- Задаёт ширину линии рамки.
- `thin` — тонкая; `medium` — средняя; `thick` — толстая.
- Можно указать точный размер: `1px`, `2px`, `0.15rem`.

**Вид линии**
- `solid` — сплошная линия.
- `dashed` — линия из штрихов.
- `dotted` — линия из точек.
- `double` — две параллельные линии.
- `groove` / `ridge` — рельефная линия с эффектом углубления или выступа.
- `inset` / `outset` — эффект вдавленной или выступающей рамки.
- `none` — рамка не рисуется.

**Цвет**
- Можно указать название: `teal`.
- HEX: `#60a4a1`.
- Функции: `rgb()`, `hsl()`.
- `transparent` — полностью прозрачный цвет.

## Требования к тексту

- Писать простыми точными словами, без расплывчатых фраз вроде «изменяет внешний вид».
- Объяснять, что именно меняется на элементе.
- Перечислять варианты по отдельности, а не сваливать их в одну строку.
- Для каждого варианта кратко описывать видимый или функциональный результат.
- Приводить короткий пример там, где без него трудно понять запись.
- Не повторять одно и то же в разных пунктах.
- Не добавлять длинные справочные отступления, редкие детали и дополнительные функции, не нужные для понимания свойства.
- Не делать из описания формальную спецификацию CSS.

## Интерфейс

- Справочник остаётся компактным на верхнем уровне.
- Свойство раскрывается отдельно.
- Его смысловые пункты раскрываются каждый по отдельности.
- Подробности не должны быть постоянно открыты и занимать весь экран.
