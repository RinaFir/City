Справочник CSS

селектор { свойство: значение; }

Селектор выбирает элементы сцены. Свойство определяет, что меняется, а значение — как именно.

.window — все окна; .building-center — центральное здание; :hover — состояние при наведении.

Подсказка
Выбери класс .window и используй свойство border-radius.
Показать решение
.window {\n  border-radius: 4px;\n}
